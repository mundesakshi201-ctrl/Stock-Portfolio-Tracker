# Stock Portfolio Tracker

## CodeAlpha Internship - Task 2

### Project Overview

Stock Portfolio Tracker is a simple Python-based application that allows users to enter stock names and quantities and calculates the total investment value of their portfolio.

The project uses predefined stock prices stored in a Python dictionary.

---

## Objective

The main objective of this project is to create a simple stock portfolio tracking system using Python.

It demonstrates the use of:

- Python dictionaries
- User input and output
- Arithmetic operations
- Loops
- Conditional statements
- Lists
- File handling
- Input validation

---

## Features

- Display available stocks and their prices
- Accept stock name from the user
- Accept quantity of stocks
- Calculate investment for each stock
- Calculate total portfolio investment
- Validate stock names
- Validate stock quantity
- Allow multiple stocks to be added
- Save portfolio results in a text file

## Formula

The investment value of each stock is calculated using:

Investment = Stock Price × Quantity

The total investment is calculated as:

Total Investment = Sum of all Stock Investments
